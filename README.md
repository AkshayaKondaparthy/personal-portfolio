## 📌 About the Project

This project is a **responsive and accessible personal portfolio web application** developed as part of **Assignment-1 for Full Stack Development (FSD)**.

The portfolio presents my academic background, technical skills, projects, internships, achievements, and contact information in a modern and responsive interface.

The application is developed using **HTML5, CSS3, Bootstrap 5, and JavaScript ES6+**, with additional JavaScript-based interactive features for an engaging user experience.

## ⚡ JavaScript Features

The portfolio includes multiple JavaScript-powered interactive features.

### 🌙 1. Dark / Light Theme

Users can switch between dark and light themes.

The selected theme is stored using **localStorage**, allowing the preference to persist across page reloads.

### 🔎 2. Project Category Filtering

Projects can be filtered dynamically based on categories such as:

- Web Development
- Artificial Intelligence
- Cybersecurity

### 🧩 3. Dynamic Project Cards

Project information is stored using **JavaScript arrays and objects** and rendered dynamically into the page.

### ⌨️ 4. Typing Animation

The home section includes a dynamic typing animation displaying different professional interests.

### 📩 5. Contact Form Validation

The contact form performs client-side validation for:

- Name
- Email
- Subject
- Message

### ✅ 6. Dynamic Form Messages

Success and error messages are displayed dynamically based on form validation results.

### ⬆️ 7. Scroll-to-Top Button

A scroll-to-top button appears while navigating through longer sections of the portfolio.

### 🧭 8. Active Navigation

The navigation bar dynamically highlights the currently visible section while scrolling.

### 📱 9. Responsive Mobile Navigation

The Bootstrap mobile navbar provides responsive navigation on smaller screens.

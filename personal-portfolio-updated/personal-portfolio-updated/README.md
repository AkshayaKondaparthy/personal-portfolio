# Akshaya Kondaparthy - Personal Portfolio

Responsive and accessible portfolio developed for Assignment-1 using:

- HTML5
- CSS3
- Bootstrap 5
- JavaScript ES6+

## Included Sections

Home, About, Education, Skills, Projects, Internships, Achievements and Contact.

## JavaScript Features

1. Dark/light theme switching with localStorage
2. Project category filtering
3. Dynamic project cards using arrays and objects
4. Typing animation
5. Client-side contact form validation
6. Dynamic success/error messages
7. Scroll-to-top button
8. Active navigation while scrolling
9. Bootstrap mobile navbar interaction
